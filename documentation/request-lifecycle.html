⚙️ Laravel Request Lifecycle

🌐
1. Browser
User submits the registration form
POST http://localhost:8000/students
1
🔀
2. Route
Laravel matches the request to a route definition
Route::post('/students', [StudentController::class, 'store'])
2
🎮
3. Controller
StudentController@store() method is invoked
StudentController::store(Request $request)
3
✅
4. Validation
Laravel validates all fields — fails redirect back with errors, passes continue
$request->validate([...rules...])
4
📦
5. Model
Eloquent Student model prepares data for insertion
Student::create($validated)
5
🗄️
6. Database
Record is inserted into the MySQL students table
INSERT INTO students (...) VALUES (...)
6
📁
7. File Storage
Profile picture is stored in storage/app/public
$request->file('profile_picture')->store('profile_pictures', 'public')
7
🎉
8. Response
Redirect to student profile page with flash success message
redirect()->route('students.show', $student->id)->with('success', '...')
8
